# 📊 Retail Sales Analytics

An end-to-end Data Analytics project using Python, MySQL, SQL, and Power BI to analyze retail sales performance and deliver business insights through interactive dashboards.

## Project Overview

This project analyzes retail sales data from a Superstore dataset.

The workflow includes:

- Data Cleaning using Python
- Exploratory Data Analysis (EDA)
- Feature Engineering
- SQL Analysis using MySQL
- Data Modeling in Power BI
- DAX Measures
- Interactive Dashboards
- Business Insights

## Key Business Insights

- Technology generated the highest sales.
- West region contributed the highest revenue.
- Consumer segment generated the highest sales.
- Furniture had the lowest profit margin.
- Higher discounts negatively affected profitability.
